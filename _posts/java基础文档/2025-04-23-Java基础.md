### **一、Java语言特性**
1. **面向对象编程（OOP）**
   - 封装、继承、多态、抽象
   - 接口与抽象类的区别
   - 静态方法与实例方法的区别
2. **平台无关性**
   - JVM、JRE、JDK 的作用与区别
   - 字节码（.class文件）的执行原理
3. **自动内存管理**
   - 垃圾回收（GC）机制及常见算法
4. **其他特性**
   - 自动装箱与拆箱（Boxing/Unboxing）
   - 泛型（Generics）
   - 注解（Annotation）
   - Lambda表达式（Java 8+）
   - 模块化系统（Java 9+）

---

### **二、核心语法与关键字**
1. **基本数据类型**
   - 8种基本类型（int、char、boolean等）
   - 包装类（Integer、Character等）
   - 值传递 vs 引用传递
2. **变量与运算符**
   - `final`、`static`、`volatile` 关键字
   - `==` 与 `equals()` 的区别
   - `hashCode()` 的作用
3. **流程控制**
   - 循环结构（for、while）
   - 分支结构（if-else、switch）
4. **异常处理**
   - `try-catch-finally` 块
   - 检查异常（Checked Exception）与未检查异常（Unchecked Exception）
   - `throw` 与 `throws` 的区别
5. **关键字**
   - `transient`（序列化忽略字段）
   - `synchronized`（线程同步）
   - `default`（接口默认方法）

---

### **三、核心类库**
1. **String类**
   - `String`、`StringBuilder`、`StringBuffer` 区别
   - 字符串常量池（String Pool）
2. **Object类**
   - `toString()`、`equals()`、`clone()` 方法
   - 深拷贝与浅拷贝
3. **集合框架（Collection Framework）**
   - List（ArrayList vs LinkedList）
   - Set（HashSet vs TreeSet）
   - Map（HashMap、LinkedHashMap、ConcurrentHashMap）
   - `Comparable` 与 `Comparator` 接口
4. **IO/NIO**
   - 字节流（InputStream/OutputStream）
   - 字符流（Reader/Writer）
   - NIO的Buffer、Channel、Selector

---

### **四、多线程与并发**
1. **线程基础**
   - 创建线程的方式（继承Thread、实现Runnable、Callable）
   - 线程生命周期（新建、就绪、运行、阻塞、死亡）
2. **线程同步**
   - `synchronized` 关键字
   - `ReentrantLock` 与 `ReadWriteLock`
   - 死锁的产生与避免
3. **并发工具类**
   - `volatile` 关键字（可见性、禁止指令重排）
   - `ThreadLocal` 的作用与内存泄漏问题
   - 线程池（ThreadPoolExecutor）
   - 原子类（AtomicInteger、CAS原理）
4. **JUC包（java.util.concurrent）**
   - `CountDownLatch`、`CyclicBarrier`、`Semaphore`
   - `ConcurrentHashMap` 实现原理

---

### **五、JVM与内存管理**
1. **内存区域**
   - 堆（Heap）与栈（Stack）
   - 方法区（元空间）、程序计数器、本地方法栈
2. **垃圾回收（GC）**
   - 分代回收（Young/Old Generation）
   - GC算法（标记-清除、复制、标记-整理）
   - 常见GC器（Serial、Parallel、CMS、G1、ZGC）
3. **类加载机制**
   - 类加载过程（加载、验证、准备、解析、初始化）
   - 双亲委派模型
   - 打破双亲委派（Tomcat类加载机制）

---

### **六、设计模式与编码实践**
1. **常用设计模式**
   - 单例模式（懒汉式、饿汉式、双重检查锁）
   - 工厂模式、抽象工厂模式
   - 观察者模式、装饰器模式
2. **编码规范**
   - 代码可读性（命名、注释）
   - 异常处理最佳实践
   - 资源释放（try-with-resources）

---

### **七、新特性（Java 8+）**
1. **Lambda表达式**
   - 函数式接口（`@FunctionalInterface`）
2. **Stream API**
   - 集合的流式操作（filter、map、reduce）
3. **Optional类**
   - 避免空指针异常
4. **模块化系统（Java 9）**
   - `module-info.java` 文件
5. **记录类（Record，Java 14+）**
   - 简化不可变类的定义
