我系统地学习了 Java 语言及其相关生态，包括 Java 基础、面向对象编程、集合、多线程等核心内容，并掌握了主流的开发框架，如 Spring Boot、Spring MVC、MyBatis 等。

在大三结束后的暑假，我获得了第一份实习机会，在北京一家外包公司，被派驻到宝马总部的数据部门，主要参与车载日志的采集与处理，接触了 SPL 和数据可视化方面的内容。但在实践过程中，我意识到这与我未来想专注的后端开发方向有偏差。

因此我主动跳槽，加入了一家中小型 AI 技术公司，正式转向 Java 服务端开发。在这家公司期间，我参与并主导了多个核心模块的开发工作，其中包括一个**基于 WebRTC 实现的实时语音对话系统**。我从底层流程设计开始，搭建了从语音采集、流式传输、语音识别、大模型调用到语音合成的完整链路，并使用多线程优化了用户状态的并发管理，提升了系统的稳定性和响应效率。

此外，我还参与了数据库性能优化工作，比如 MySQL 索引调整、SQL 语句优化等，提升了整体的数据处理能力。

我对技术充满热情，未来希望深入底层架构，增强系统设计能力，逐步成长为一名具备全局视野的架构师。
